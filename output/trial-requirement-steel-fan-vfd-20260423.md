# 试用需求：某钢铁厂烧结环冷风机高压变频节能改造

## 1. 项目背景

某钢铁厂烧结区域现有 1 台环冷风机采用工频运行，存在启动冲击大、调节范围有限、能耗偏高的问题。现计划实施高压变频节能改造，在保留现有主电机和上位控制系统总体架构的前提下，实现软启动、变频调速、联锁保护和运行可视化。

本项目目标是形成一份可用于技术交流和商务投标的技术方案，重点说明系统方案、供货范围、接口条件、控制逻辑、保护功能、安装调试和售后服务。

## 2. 已知基础条件

- 应用对象：烧结环冷风机
- 数量：1 套
- 电机形式：高压异步电机
- 电机额定功率：1250kW
- 电机额定电压：10kV
- 电机额定频率：50Hz
- 电机额定转速：约 990rpm
- 负载特性：风机类平方转矩负载
- 安装地点：钢铁厂烧结区域电气室
- 环境温度：-5°C 至 45°C
- 海拔：不高于 1500m
- 控制方式：就地 + 远程 DCS
- 通讯要求：Modbus TCP

## 3. 方案边界

- 新增 1 套高压变频装置及其附属控制系统
- 保留原有高压开关柜和主电机主体
- 需考虑与现有 DCS 系统的硬接点及通讯接口
- 需给出系统主接线思路、控制联锁逻辑和保护配置
- 不要求本次范围内更换主电机
- 可选项单独说明：工频旁路、输入输出滤波、远程运维模块

## 4. 重点技术要求

- 变频器适用于风机类负载，具备平滑启动和调速节能能力
- 装置应具备完善的过压、欠压、过流、过温、接地、缺相、通讯异常等保护
- 支持就地触摸屏操作和远程 DCS 控制切换
- 需明确启停顺序、联锁条件、故障告警和状态反馈点表
- 需说明与高压开关柜、DCS、现场仪表之间的 DI/DO/AI/AO/通讯接口
- 需提供主要技术参数表、柜体布置要求、进出线方式和散热/维护空间要求

## 5. 交付要求

- 技术方案书
- 主要设备配置表
- 供货范围及备件清单
- 电气原理图/接口表
- 安装调试计划
- FAT/SAT 方案
- 培训与售后服务承诺

## 6. 验收关注点

- 启动电流显著低于工频直启
- 满足风机变工况调速需求
- 与现有 DCS 联锁、监控、告警对接清晰
- 资料齐套，便于后续实施和业主评审
