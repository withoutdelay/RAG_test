# ADR-001 产品驱动方案设计层

## 状态

Accepted

## 背景

现有方案生成链路过度依赖历史文档复用，面对新产品组合时缺少稳定事实源，导致参数与章节结构容易沿袭旧项目。

## 决策

在 `Requirement -> Evidence` 之后插入 `Solution Design` 层，使用 PostgreSQL 产品目录、`solution_snapshot` 持久化快照和前端 Solution 工作台承接产品选型、接口规划、约束和待确认项。

## 后果

- 大纲、章节生成和校验拥有统一的产品上下文。
- 真实方案回归可以核对目录版本与选型输出。
- 发布演练需要同步校验产品目录迁移与回滚路径。
